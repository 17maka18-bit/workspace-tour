# Interactive Workspace Tour (CSS Positioning)

ეს პროექტი წარმოადგენს პრაქტიკულ დავალებას, რომლის მიზანია **CSS Positioning** ინსტრუმენტების (`relative`, `absolute`, `fixed`) და ფენების იერარქიის (`z-index`) სიღრმისეულად ათვისება სუფთა HTML-სა და CSS-ში.

## 🚀 პროექტის შესახებ
ვებ-გვერდზე გამოსახულია დეველოპერის სამუშაო მაგიდის ფოტო, რომელზეც დატანილია ინტერაქციული წერტილები (**Hotspots**). მაუსის მიტანისას თითოეულ ნივთზე (მონიტორი, კლავიატურა, მაუსი, ყავის ჭიქა, მცენარე, ყურსასმენი, ბლოკნოტი) იხსნება საინფორმაციო ბარათი (**Tooltip**) პროდუქტის დეტალებითა და ფასით. ეკრანის კუთხეში კი მუდმივად ფიქსირდება დამხმარე მცურავი ვიჯეტი (`?`).

## 🛠 გამოყენებული ტექნოლოგიები
* **HTML5** (სემანტიკური ტეგები: `<header>`, `<main>`, `<section>`, `<article>`, `<aside>`)
* **CSS3** (Flexbox, CSS Positioning, Transitions, Hover Effects)
